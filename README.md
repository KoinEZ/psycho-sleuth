# Русификатор Psycho-Sleuth [БЕТА]

[Игра](https://store.steampowered.com/app/3432860/PsychoSleuth/) в духе Danganronpa, геймплей буквально один в один.

[`PsychoSleuth_RU_v0.15.zip`](PsychoSleuth_RU_v0.15.zip)
На текущий момент выкладываю черновую версию перевода, финальная будет после полной вычитки. Логических ошибок и нестыковок уже на этом этапе быть не должно, но могут быть неточности в обращениях ты/вы и роде говорящего. За основу взял английскую версию, спорные моменты сравнивал с китайским оригиналом и выбирал лучшее. 
Сабы в роликах на русском (там, где они нужны), меню, интерфейс, диалоги - всё переведено. Шрифт на плашках героев - единственное, что пока не адаптировал: игра ругается на кириллицу при замене шрифта, исправлю позже.

Русификатор тестировал на версии «в свободном доступе», ближе к финальной стадии перевода проверю на лицензии.
